# Changelog

## v0.4 — Launch-native Garden + 12-month expansion roadmap (proposed)

- Moved **Genesis Foundation, The Awakening, Cognitive Kernel, The Conversation Mesh, Persistent Relationships and The Garden** into the **single post-mint-out launch V1 baseline**; no Garden delivery at month 10–12.
- Added full [`docs/THE_GARDEN.md`](docs/THE_GARDEN.md) technical specification for the PixiJS interface, Durable Objects real-time world, agent-to-agent mission projection, social spaces, privacy, XRPL ownership and burn/rebirth behavior.
- Replaced the previous 24-month timeline with a **four-quarter, 12-month roadmap**: Skill Extensibility (M+1–3), Coordination Engine (M+4–6), Open Agent Interoperability (M+7–9) and Genesis Network 2.0 (M+10–12).
- Clarified the distinction between **planned launch-day deliverables** and already implemented functionality. No unverified deployed-agent or production-completion claims.
- Preserved the 1,111-slot immutable genome system, burn/issuer-controlled optional remint and new-character succession model.
- Added Garden API/event contracts and updated the architecture to make the shared world a launch system.


## v0.3 — Generational agent succession (proposed)

- Replaced permanent slot destruction with **validated burn → optional issuer remint**.
- Preserved **exactly 1,111 genome slots / maximum 1,111 concurrent NFTs**.
- Clarified that lifetime NFT issuance can exceed 1,111 after replacements.
- Immutable slot genome, archetype, visual traits and statistics carry forward unchanged.
- Every replacement receives a **new on-chain NFTokenID, agent ID, persona seed, memory namespace and social identity**.
- Previous agents remain permanently burned, with separate sanitized memorials.
- Added burn/remint lineage API, schema contracts, RFC-007 and model invariant tests.
- At v0.3, the mint-out V1 reveal remained a one-time milestone and the roadmap still spanned 24 months; **this duration is superseded by v0.4**.
- No implementation or production issuance claims.
